# Understanding HTML Tables

This repository contains examples of HTML tables and various other HTML elements.

## Table Tag

HTML tables are used to display data in rows and columns. Here are some examples:

### Basic Table
Uncomment the following code to display a basic table with data about employees:

```html
<!--
<table border="1">
    <tr>
        <th>No</th>
        <th>Full Name</th>
        <th>Position</th>
        <th>Salary</th>
    </tr>
    <tr>
        <td>1</td>
        <td>Bill Gates</td>
        <td>Founder Microsoft</td>
        <td>$1000</td>
    </tr>
    <!-- Add more rows as needed -->
</table>
-->
```

### Timetable Table
Uncomment the following code to display a timetable using rowspan and colspan attributes:

```html
<!--
<table border="1">
    <tr align="center">
        <th colspan="6">Time Table</th>
    </tr>
    <tr>
        <th rowspan="6">Hours</th>
        <td>Mon</td>
        <td>Tue</td>
        <td>Web</td>
        <td>Thu</td>
        <td>Fri</td>
    </tr>
    <!-- Add more rows as needed -->
</table>
-->
```
