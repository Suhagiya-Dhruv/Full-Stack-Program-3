# HTML Information

This repository contains information about HTML, including semantic and non-semantic tags, block and inline tags, self-closing tags, and their uses.

## Semantic Tags

Semantic tags provide meaning to the content they enclose. Examples include:
- `<header>`
- `<article>`
- `<main>`
- `<section>`
- `<footer>`
- `<address>`
- `<aside>`

## Non-Semantic Tags

Non-semantic tags are generic and do not inherently provide meaning. Examples include:
- `<h1>` to `<h6>`
- `<div>`
- `<nav>`
- `<p>`
- `<i>`
- `<b>`

## Block Tags

Block tags define sections or blocks of content. Examples include:
- `<h1>` (Heading 1)
- `<p>` (Paragraph)

## Inline Tags

Inline tags are used within block-level elements and do not create new lines. Examples include:
- `<button>`
- `<span>`
- `<input>`

## Self-Closing Tags

Self-closing tags do not have a separate closing tag. Examples include:
- `<base />`
- `<hr/>`
- `<br/>`

## Uses of Tags

HTML tags can be used for various purposes, including defining headings, paragraphs, emphasizing text, creating links, and collecting user input.
